# CHAPTER 5

## RECOMMENDATIONS

Additional functions and enhancements can be added to improve the performance and usefulness of the B-Health system. The researchers recommend reintroducing the vaccination module as a full vaccination management feature in a future version. This would include a vaccination tracker in the resident mobile application showing administered vaccines and dosage schedules, automated vaccine reminders sent to residents 7 days, 3 days, and 1 day before their scheduled vaccination, and alerts for missed or overdue doses. On the administrative website, a vaccination management page would allow staff to record administered vaccines, update statuses, and generate vaccination coverage reports per purok.

The study also suggests integrating an SMS gateway so that residents without stable internet access can still receive appointment updates and health reminders via text message. Furthermore, the appointment booking screen could be improved by displaying real-time slot availability per service and per hour, allowing residents to see open schedules before submitting a request. Adding a dedicated reports table would also allow the system to save generated reports so that administrators can retrieve them without regenerating the data.

Moreover, the researchers recommend developing a teleconsultation module that would allow residents to request online consultations through video or chat for follow-up checkups that do not require physical visits. A medicine inventory module with expiration and low-stock alerts, together with a digital queuing system for walk-in patients, would further streamline the day-to-day operations of the health center. Since the current application is distributed as an Android APK only, developing an iOS version would also make the system accessible to residents who use iPhones, which is feasible because the application was built with Ionic and Capacitor. For improved accessibility, the mobile application could support offline viewing of health records, services, and emergency contacts, as well as Filipino and English language options.

Lastly, the researchers recommend strengthening the security and data integrity of the system by implementing two-factor authentication for administrators, resident ID verification during registration, proper foreign keys in place of name-based references, and an audit trail of administrative actions. They also advise that the barangay health center formally adopt the system through staff training, a community information drive for residents, and regular database backups to ensure its continued and reliable operation.
